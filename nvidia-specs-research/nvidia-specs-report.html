⚠️
注意：B200 的 SM 数量和 CUDA cores 数为基于消费级 GB200 die 配置的推断值，NVIDIA 未完全公布 B200 单 GPU 的完整 SM 规格。Rubin (R200) 规格为 GTC 2026 预发布数据。

Hopper 关键微架构创新

  • Transformer Engine — FP8↔FP16 动态精度管理，LLM训练快 9x，推理快 30x
  • DPX Instructions — 动态规划算法加速 7x vs A100
  • Thread Block Cluster — 跨 SM 线程块协作，最大 cluster size = 16
  • Distributed Shared Memory — 直接 SM-to-SM 通信 (loads/stores/atomics)
  • Tensor Memory Accelerator (TMA) — 全局内存↔共享内存双向异步传输，支持 5D tensors
  • Page Migration Engine — 硬件加速 CPU↔GPU 页面迁移

Blackwell 关键微架构创新

  • 第5代 Tensor Core — 原生支持 sub-8-bit (MXFP4, MXFP6)
  • 第2代 Transformer Engine — FP4 支持，推理吞吐量翻倍
  • NV-HBI — 双die间 10 TB/s 芯片间互连，全cache coherency
  • AI Management Processor (AMP) — RISC-V 专用调度引擎
  • Micro-tensor 切片 — 细粒度 tensor 切片适配低精度计算

3. ICMS存储架构与内存系统

🔍
重要术语纠正：ICMS 并非 "Integrated Coherent Memory System"，而是 Inference Context Memory Storage（推理上下文内存存储），也称为 CMX (Context Memory Storage)。这是 NVIDIA 在 CES 2026 上宣布的全新 AI 存储平台。

规格项数值/描述

定位在 GPU HBM (G1) 和企业存储 (G4) 之间创建 G3.5 层级
处理器NVIDIA BlueField-4 DPU
每Pod共享容量PB 级
TPS提升最高 5x（长上下文/代理工作负载）
能效提升比传统存储高 5x

协议NVMe/NVMe-oF, NVMe KV 扩展
