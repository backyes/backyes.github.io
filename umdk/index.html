概览

UMDK（Unified Memory Development Kit，灵衢内存语义开发包）是支持 UB（Ultra-Bus）协议栈的全栈软件框架，涵盖 URMA（RDMA 类通信）、URPC（统一远程过程调用）、DLock（分布式锁）、UMS（统一内存语义）四大组件。本 Survey by AI 项目对 UMDK 的核心组件进行了源码级深度分析，覆盖通信加速库 CAM 的完整算子实现与 URPC 框架的全栈架构。

UB 协议栈的核心创新：Transport/Transaction 分离 + Native load/store 延迟（500ns vs RoCE 2236ns, 4.47×）+ 分级定序（Graded Ordering）。

CAM（Communication Acceleration Module）位于 URMA 之上，为 MoE 专家并行提供 EP Normal 和 EP Low-Latency 两类通信算子。URPC 则构建在 URMA 的事务层之上，提供统一远程过程调用语义。

核心发现

从 CAM 和 URPC 源码分析中提炼的关键架构洞察：

  • Zero-Buffer 流水线：EP Normal 模式通过精心设计的 Notify→Dispatch→Combine 三阶段同步协议，实现零额外 buffer 的通信流水线，将中间数据直接写入目标地址。
  • 8+4 阶段细粒度同步：EP Low-Latency 模式将 Dispatch 拆为 8 阶段、Combine 拆为 4 阶段，每阶段仅同步必要的最小数据集，实现通信延迟的极致压缩。
  • Fused Deep MoE 三变体：BF16 / W4A8 / FWK 三种精度变体共享三阶段流水线架构，通过 AIC/AIV 异构执行模型实现计算-通信深度重叠。
  • Catlass TPL 集成：GEMM 引擎深度集成 NVIDIA Catlass 模板库，通过 Tiling Key 位掩码实现灵活的 tiling 策略选择。
  • URPC 全栈路径：从用户态 verb 到内核态 uburma.ko → ubcore.ko，URPC 的控制面与数据面分离设计保证了高吞吐与低延迟的平衡。
  • UBPlus 增强协议：URPC 在 UB 事务层之上构建了 UBPlus 协议，扩展了内存导入、Keepalive、流量控制等高级语义。
