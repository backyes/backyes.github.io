关键洞察

  • 四层动态分发：dp.c → queue_ops → send_recv_send → urma_post → bondp_post
  • 带内控制：利用 immediate 数据编码流控、内存导入、反向拉取等控制协议
  • 并发安全：tx_ctx 双次释放、req_entry hash+线性探测、读写锁分离
  • 资源复用：JFR/JFC 通过 ref_cnt 在多个队列间共享
  • 用户可选：每一层增量功能都是可选的（feature flag）
