V2 深潜问答

🔥 最新 · ElasticBuffer 第一性原理深潜（13 问）

  • Q1 ElasticBuffer 统一 Normal/LL：Buffer 是一等公民，差异仅在 SM/QP 参数
  • Q2 SM 估算本质：Roofline 模型，num_experts 和 num_topk 决定 buffer 寻址粒度
  • Q3 TopK 复制机制：dispatch 内完成 token 复制 + topk buffer 生成
  • Q4 Decode 路由缓存：100% cache，skip layout recomputation 和 CPU sync
  • Q5 0 SM 先验知识：数据面与控制面分离，NIC DMA 搬数据
  • Q6 Engram 复用：完全复用 ElasticBuffer API，共享底层资源
  • Q7 FP8 Dispatch vs BF16 Combine：节省 50% 带宽 vs 保证累加精度
  • Q8 async_with_compute_stream：分层 overlap，非放弃指令级融合
  • Q9 NV Gin 架构：GPU-Initiated Networking，1.3x 带宽，4x SM 节省
  • Q10-Q11 流量隔离：优先 VL 隔离，禁用拥塞控制
  • Q12 CFT：Compute Fabric Transport，小 token 优化
  • Q13 Zero Copy/Eager/TMA：消除拷贝、降低 RTT、数据面卸载
  • Q14 AntGroup 优化：Normal-SMFree、LL-SBO、LL-Layered
